# backend

The Python backend for **NBA Player Highlights** — the clip engine, clip library, compose, and
YouTube publish layers, driven as scripts (see `scripts/`). Start at the repo root
[README.md](../README.md) and [docs/STRATEGY.md](../docs/STRATEGY.md).

```bash
uv sync                       # install (Python 3.12; FFmpeg + ffprobe on PATH)
uv run pytest tests/ -v       # tests
```
